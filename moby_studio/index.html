? Manual del Visor
Uso recomendado para probar la experiencia final con MindAR.

1. Abrir la experiencia

En PC usa localhost para revisar la escena. En telefono usa un tunel HTTPS, porque los navegadores moviles bloquean la camara si la pagina no es segura.

2. Activar camara RA

Presiona Camara RA y acepta permisos. Si el navegador pregunta por camara frontal o trasera, usa la trasera para detectar mejor el target fisico.

3. Detectar el target

Apunta a la imagen fisica entrenada. Mantén buena luz, evita reflejos y procura que el target ocupe una parte clara de la pantalla.

4. Ver contenido AR

Cuando MindAR detecta el target, el contenido anclado aparece sobre la imagen. Usa los controles flotantes para acercar, alejar o ajustar escala durante la prueba.

5. Modo presentacion

Presentar oculta la interfaz para dejar limpia la demostracion. Vuelve a presionarlo para recuperar botones, chat y estado.

6. Preguntas y voz

Puedes escribir o dictar preguntas sobre la escena. La respuesta por voz se activa con el checkbox inferior y depende del navegador.

Problemas comunes

  • Sin camara: revisa HTTPS, permisos y que otro programa no la tenga ocupada.
  • No detecta: valida que el `.mind` corresponda a la imagen fisica.
  • Se pierde el tracking: mejora luz, distancia y estabilidad del telefono.
